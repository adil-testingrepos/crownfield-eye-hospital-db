# Crownfield Eye Hospital Database Project (CPU4:103)

## Student Details
- **Module:** CPU4:103 Introduction to Database
- **Scenario:** Crownfield Eye Hospital NHS Foundation Trust Ophthalmology Database

## Repository Structure & Execution Order
Run the SQL files in MySQL Workbench in the following numerical order:
1. `01_schema.sql` - Creates the database, tables, primary keys, and foreign key constraints.
2. `02_seed_data.sql` - Populates tables with original and synthetic records, including transaction tests.
3. `03_individual_queries.sql` - Contains the 6 required individual SQL queries (Aggregate, Joins, Left Join, CTE).
4. `04_procedure_and_trigger.sql` - Implements the stored procedure and validation trigger.
5. `05_security_and_transactions.sql` - Defines user roles, privilege grants, and password hashing.
6.  06_ERD     Conceptual and Logical ERD
## System Prerequisites
- MySQL Server 8.0+
- MySQL Workbench
